- **Sensor Suite**: 9 Independent Sensor Input Channels

---

## 🌟 Interactive Experience & Workflow

### 1️⃣ Screen 1: Sensor Channel Console (100% English)
- **Calibrated Water Source Profiles:**
  - 🚰 Municipal Treated Tap Water (Safe)
  - 🧴 RO Purified Mineral Water (Pristine)
  - 🏖️ Coastal Ocean Seawater (Unsafe)
  - 🏞️ Turbid River / Pond Water (Contaminated)
  - 🌧️ Fresh Harvested Rainwater (Clean)
  - 🏭 Industrial Chemical Effluent (Hazardous)
- **9 Independent Physicochemical Sensor Channels:**
  - pH Level, Hardness, Solids / TDS
  - Chloramines, Sulfate, Conductivity
  - Organic Carbon, Trihalomethanes, Turbidity
- **Execute Button:** `⚡ Execute Sensor Diagnostic & Launch Anime Simulation`

### 2️⃣ Screen 2: Full-Screen 2D Anime Simulation View
- **Hardware Telemetry HUD:**
  - `AQUAPROBE PRO-9 SENSOR TELEMETRY • GRID ACTIVE • 60 FPS`
  - Real-time Potability Drinking Probability Meter
  - Optical State Telemetry: Sparkling Turquoise River vs Murky Acidic Sludge
- **Studio Ghibli & Makoto Shinkai Anime Landscape:**
  - 2D Hand-drawn tropical beach & winding freshwater river meeting ocean.
  - Live animated sparkling caustics (`✨`) and manga seagulls.
- **🔄 Recalibrate & Test New Water Sample:** 1-click button to reset and test a new sample.

## 🚀 How to Run

Double-click **`run_app.bat`** or run in terminal:
```powershell
python -m streamlit run app.py
```
Open your browser at `http://localhost:8501`.
